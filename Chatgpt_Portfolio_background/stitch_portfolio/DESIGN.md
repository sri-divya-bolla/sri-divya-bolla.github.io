## Brand & Style

This design system expresses a refined, cosmic avant-garde aesthetic tailored for personal creative direction, technical architecture, and spatial interface portfolios. It balances deep-space atmospheric resonance with ultra-precise, instrument-grade visual hierarchy.

The visual theme combines deep cosmic voids, luminescent silver starlight, and muted nebula lavender tints. It merges **Glassmorphism** with **Futuristic Neo-Grotesque** typographic precision. Interfaces evoke viewing high-end mission consoles, observational astrophysics dashboards, and high-fidelity fluid portfolios. Interactions emphasize zero-gravity smoothness, light refraction, and subtle celestial halos.

## Colors

The palette simulates the contrast of interstellar space: pure void darks, muted nebular luminescence, and starlight reflection.

### Dark Mode (Default)
- **Void Canvas (`background`)**: `#000000` — Pure abyss. Provides infinite contrast for ethereal borders and floating glass structures.
- **Deep Slate Surface (`surface`)**: `#242A26` — Deep galactic basalt with an emerald tint. Used for primary card bodies and navigation panels with translucent opacity overlays.
- **Starlight Silver (`primary`)**: `#B2BEB5` — Polished starlight ash. Powers key callouts, active indicators, and high-clarity strokes.
- **Nebula Lavender (`secondary`)**: `#BDB2BA` — Subdued ethereal rose-lavender for supporting metadata, interactive pill states, and ambient glow reflections.
- **Deep Orbit (`tertiary`)**: `#4E5D53` — Structural divider tone, subtle hover fills, and secondary icon foundations.
- **Cosmic Light (`text-primary`)**: `#FFFFFF` — Sharp legibility across deep surfaces.
- **Starlight Subdued (`text-secondary`)**: `#A1AAA4` — Attenuated body and descriptive text.

### Light Mode (Alternate)
- **Cosmic Cloud Canvas (`background`)**: `#FFFFFF` — Crisp daylight void.
- **Cloud Slate Surface (`surface`)**: `#D8DEDA` — Muted celestial mist surface for panels.
- **Void Core (`text-primary`)**: `#000000` — Primary text rendering for high-contrast accessibility.
- **Primary Accent (`primary`)**: `#6A756D` — Deepened starlight gray adjusted for contrast compliance over light surfaces.
- **Secondary Accent (`secondary`)**: `#7D727A` — Deepened nebula lavender for legible light-mode indicators.

## Typography

The typographic hierarchy relies on a dual pairing: **Space Grotesk** commands prominent editorial headlines with geometric propulsion, while **Inter** ensures crystalline readability for descriptions, project briefs, and case study narratives.

**JetBrains Mono** operates as the technical telemetry layer. It is used strictly for timestamps, category coordinates, git commits, index numbers (e.g., `01 // PROJECT`), and technology stack chips. All monospaced tags use uppercase styling with open letter-spacing to reinforce precision instrumentation.

## Layout & Spacing

The portfolio is architected mobile-first using a fluid grid system that responds continuously to handheld touch interaction:

- **Mobile (< 768px)**: 4-column fluid layout with dynamic full-width edge snapping. Margin defaults to `1.25rem` (`margin`), leaving breathable negative space around glass containers.
- **Tablet (768px - 1024px)**: 8-column layout with `1.5rem` gutters.
- **Desktop (> 1024px)**: 12-column constrained fluid grid (max width: `1280px`), centered within deep void margins (`3.5rem`).

Horizontal gesture lanes are native to mobile screens: portfolio projects and skill nodes flow along touch-enabled x-axis carousels with magnetic snapping points (`scroll-snap-type: x mandatory`).

## Elevation & Depth

Visual hierarchy uses frosted glassmorphism, refractive luminous borders, and ambient starlight bloom instead of drop shadows:

- **Deep Space Base (Elevation 0)**: `#000000` solid background with occasional radial gradients of muted emerald-slate (`#242A26`) and soft nebula magenta tints at `10%` opacity.
- **Glass Panel (Elevation 1)**: Primary cards use `background: rgba(36, 42, 38, 0.55)` paired with `backdrop-filter: blur(16px)` and `-webkit-backdrop-filter: blur(16px)`. Border is a 1px composite: `rgba(178, 190, 181, 0.18)`.
- **Active / Floating Glass (Elevation 2)**: Sticky navigation pills and elevated modals use `background: rgba(36, 42, 38, 0.75)` with `backdrop-filter: blur(24px)`. Borders glow via `box-shadow: 0 0 16px -2px rgba(178, 190, 181, 0.25), inset 0 0 0 1px rgba(189, 178, 186, 0.35)`.
- **Specular Highlights**: Top edges of cards receive an inner gradient stroke (`linear-gradient(90deg, transparent, rgba(255,255,255,0.3) 50%, transparent)`) simulating directional starlight skimming across metallic glass.

## Shapes

The design system embraces an aerodynamic, capsule-driven shape language (`level 3`). Primary interactive components, filter chips, and fixed status modules use complete pill geometry (`rounded-full` / `9999px`) to maintain fluid touch ergonomics on handheld devices.

Content cards, modals, and viewport-framing surfaces use `rounded-xl` (`3rem` or `24px` on mobile screens), delivering soft corners that keep visual tension focused on inner media and typographic details.

## Components

### Buttons
- **Primary Pill**: Full capsule (`border-radius: 9999px`). Starlight silver fill (`#B2BEB5`) with void black text (`#000000`, `Space Grotesk Medium`). Active state introduces a `0 0 20px rgba(178, 190, 181, 0.4)` glow.
- **Glass Ghost**: Capsule border with `1px solid rgba(178, 190, 181, 0.3)` and transparent fill. Text in pure white with subtle hover fill `rgba(189, 178, 186, 0.12)`.

### Sleek Pill Tabs & Navigation
- Floating bottom or top horizontal dock: `display: flex`, pill-shaped container with frosted slate glass (`rgba(36, 42, 38, 0.6)`), blurred at `20px`.
- Tab items render as mini-capsules with horizontal swipe inertia. Active tab triggers an animated pill indicator with `#BDB2BA` starlight tinting and crisp `JetBrains Mono` labels.

### Fluid Cosmic Cards
- Constructed with `24px` border-radius, `1px` starlight border, and backdrop blur.
- Includes a top-right celestial coordinate badge (e.g., `[ 01 // ARCHITECTURE ]`) set in `label-mono-md`.
- Media images inside cards feature subtle grain overlays and scale effortlessly with fluid spring physics on touch release.

### Tech Stack Chips
- Compact pills styled in `background: rgba(255, 255, 255, 0.05)`, bordered with `rgba(189, 178, 186, 0.2)`.
- Type set in `label-mono-sm` uppercase. Interactive states pulse with a faint nebula lavender outer halo.

### Checkboxes & Toggle Selectors
- Pill toggles with an inner sliding starlight sphere. Checkbox inputs are soft geometric squares (`border-radius: 6px`) with emerald slate background and silver-tinted tick marks.

### Input Fields
- Understated glass pill containers with recessed background fill `rgba(0, 0, 0, 0.4)` and a `1px` subtle outline. Focus states transition smoothly to a dual starlight border glow (`rgba(178, 190, 181, 0.6)`).
